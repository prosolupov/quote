# Quote Project 📈

Асинхронная система трансляции биржевых котировок.

## 🏗 Архитектура
Проект разделен на два основных компонента:
*   **Server**: Обрабатывает входящие запросы и транслирует котировки.
*   **Client**: Подключается к серверу, передает список тикеров из файла и слушает UDP-порт.

---

## 🚀 Запуск проекта

### 1. Запуск сервера
Сервер инициализирует TCP-слушатель для приема команд.
```bash
cargo run --bin server
```

### 2. Запуск клиента

Клиент считывает тикеры из файла и инициализирует поток данных.

```bash
cargo run --bin client -- \
    --ip-server 127.0.0.1 \
    --port-server 8080 \
    --port-udp 5456 \
    --path-file client/static/tickers.txt
```

⚙️ Параметры запуска клиента
* --ip-server IP-адрес сервера для TCP соединения
* --port-server	Порт сервера для управления (TCP)
* --port-udp Локальный порт для приема котировок (UDP)
* --path-file Путь к файлу со списком тикеров

📄 Формат файла тикеров
Файл с тикерами должен быть обычным текстовым файлом (.txt) в кодировке UTF-8.
* Каждый тикер должен располагаться на новой строке.
* Пробелы в начале или конце строки автоматически игнорируются.
* Пустые строки не обрабатываются.


Пример полной команды запуска:
```bash
cargo run --bin client -- --ip-server 127.0.0.1 --port-server 8080 --port-udp 5456 --path-file client/static/tickers.txt
```
